# Security

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/BZ110/SmolMC/security/advisories/new). Include the affected commit or tag, configuration, impact, and the smallest reproducible example you can share. Redact credentials and account data.

See the [security and trust model](docs/21_SECURITY_AND_TRUST.md) and [M4B security review](docs/M4B_SECURITY_REVIEW.md) for the current architecture and limits. The local Java bridge is optional and defaults to observe access when enabled.
